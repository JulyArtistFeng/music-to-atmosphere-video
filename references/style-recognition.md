## 各风格视觉关键词库

### 1. 真人电影感（流行/抒情/治愈）
**画面关键词**：
- 浅景深、散景（bokeh）
- 35mm 胶片质感、颗粒感
- 自然光、黄金时刻（golden hour）
- 暖色调、柔和对比
- 真人（背影/侧脸/远景，避免正脸特写）
- 日常场景：街道、咖啡店、海边、房间、天台

**镜头运动**：慢推、慢拉、固定、轻微手持

**色调**：暖橙、米黄、浅蓝、低饱和

**seedance prompt 模板**：
```
电影质感，真人风格，{场景描述}，{人物动作}，
自然光，浅景深，35mm胶片颗粒，暖色调，
{镜头运动}，氛围感，1080p，16:9
```

---

### 2. 新海诚风格（二次元/动漫风）
**画面关键词**：
- 高饱和天空、积雨云
- 光影对比强烈、丁达尔效应
- 城市风景、电车、樱花、夏日
- 细腻的背景绘制
- 动漫角色（远景/背影，避免正脸）

**镜头运动**：慢推、航拍、云层流动

**色调**：天蓝、橙黄、粉紫、高饱和

**seedance prompt 模板**：
```
新海诚风格，动漫场景，{场景描述}，
高饱和天空，积雨云，光影对比，丁达尔光效，
{镜头运动}，细腻绘制，氛围感，1080p，16:9
```

### 3. 赛博朋克（电子/赛博）

### 5. 电影动作感（摇滚/激昂）
**画面关键词**：

## 风格一致性维护

多镜头生成时，为保持风格统一：
1. 每个 prompt 都重复风格关键词（如"电影质感，35mm胶片颗粒"）
2. 色调在相邻镜头间渐变（冷蓝→暖橙，不要突然切换）
3. 人物保持同一形象描述（如"一个穿黑色风衣的年轻人"）
4. 场景之间有逻辑关联（街道→咖啡店→天台，不是随机跳跃）
5. 如果某个镜头生成失败或风格跑偏，用相同 prompt 重试，不换风格

## 曲风不明确时的决策树

```
能识别曲风吗？
├─ 能 → 查表匹配
└─ 不能 → 看情绪
    ├─ 悲伤/忧郁 → 真人电影感（冷色调）
    ├─ 欢快/治愈 → 真人电影感（暖色调）或新海诚风格
    ├─ 激昂/力量 → 电影动作感
    ├─ 神秘/诡异 → 悬疑电影感
    └─ 平静/空灵 → 自然纪录片感或新海诚风格
```
