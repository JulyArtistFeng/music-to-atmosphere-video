# 音乐氛围短片 · 2.0 本轮研究与升级

日期：2026-11-24。

## 本职与边界

以用户原曲为主时钟，将音乐结构、歌词/意象与连续视觉组织为氛围短片；支持纯器乐。

不替换原曲，不制作攻略/影视解说/实况集锦，不默认转数字人唱歌。

## 筛选方法

GitHub Repository Search（每查询按stars降序取前50项）+ 定向核查知名相关项目；按本技能职责与许可/维护状态筛选后，在本次候选池内按实际stars排序取五项。不是对全GitHub的穷尽排名，也不是文学/视觉/视频质量排行榜。

准入条件：音乐节奏/特征分析或时序视觉生成的开源项目；合成新歌、音乐播放器与通用聊天平台不作为当前任务替代。

高星只能说明关注度。组件来源只用于其支撑的环节，不能将组件说成具备整套技能能力。不同技能可以参考同一个时间轴组件，但只迁移各自的任务方法，不引入其他技能的主题、文风、交付目标或专业判据。

## 排除与不采用

- 通用模型服务平台、播放器和新歌生成不等于原曲驱动短片；不借源项目更换用户原曲。
- audioFlux（3,386 stars）和Deforum（2,280 stars）为较低星补充候选，未挤入已筛选五项。

## 实际升级

以原曲时钟做分段和剪点，处理半倍速BPM与无歌词输入，增加镜头身份锚点和歌词未知状态。

不是复制上游整套提示词，而是将其适用的方法落实到本技能的输入、决策、过程记录与验收。原功能仍保留，现有用户目标优先。

完整提交、文件指纹、候选范围和许可记录见 [upgrade-source-lock.json](upgrade-source-lock.json)。新版的实际验证和限制见仓库 README。未安装或实测这些上游项目，不声称它们已在本机可用，更不以Stars证明输出质量。
