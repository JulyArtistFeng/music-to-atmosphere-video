# 音乐氛围感视频 · 详细工作流

开始执行音乐转视频任务时完整读取。

---

## 第一步：读取输入素材

### 输入类型
| 输入 | 处理方式 |
|---|---|
| 本地音频文件（MP3/WAV） | 直接使用 |
| Suno 导出的音频 | 直接使用 |
| 在线音乐链接 | 用 doubao-video-extract 或 byted-mediakit-audio 提取 |
| 歌词文本 | 用户粘贴或从文件读取 |
| 无歌词 | 生成纯氛围视频，分镜由曲风+情绪驱动 |

### 确认信息
- 歌曲时长（决定截取哪1分钟：通常取副歌部分或最有氛围感的段落）
- 用户有无指定风格（覆盖自动匹配）
- 用户有无指定截取段落（如"从副歌开始"）

---

## 第二步：音频分析

### byted-mediakit-audio 分析
```
分析项：
- BPM（每分钟节拍数）
- 调性（大调/小调 → 欢快/悲伤倾向）
- 能量曲线（RMS响度随时间变化）
- 段落结构（前奏/主歌/副歌/桥段/尾奏）
- 人声/伴奏分离（可选）
```

### 分析结果输出
```
BPM: 120
情绪: 治愈→激昂→治愈
曲风: 流行/抒情
段落:
  前奏: 0:00-0:15
  主歌1: 0:15-0:45
  预副歌: 0:45-1:00
  副歌: 1:00-1:30
  ...
能量峰值: 1:10（副歌高潮）
```

### 1分钟截取策略
- 优先截取包含副歌的1分钟（情绪最饱满）
- 如果歌曲<1分钟，使用全曲
- 截取点：从主歌后半段开始，经过预副歌，到副歌结束（约60秒）

---

## 第三步：歌词分析

### 逐句分析模板
```
歌词原文 | 核心意象 | 情绪 | 建议画面 | 镜头运动
"站在雨中的路口" | 雨、路口、孤独 | 悲伤 | 雨夜街道，人物背影 | 慢推
"城市的霓虹闪烁" | 霓虹、城市 | 迷茫 | 城市夜景，霓虹灯 | 环绕
"我会一直奔跑" | 奔跑、希望 | 激昂 | 人物奔跑，逆光 | 跟拍
```

### 意象→画面映射
| 意象类别 | 常见词 | 视觉化方式 |
|---|---|---|
| 自然 | 雨、海、风、星空、花 | 自然风景+天气效果 |
| 城市 | 霓虹、街道、高楼、地铁 | 城市夜景/日景，人流 |
| 人物动作 | 奔跑、等待、回头、拥抱 | 真人/角色动作镜头 |
| 情绪抽象 | 孤独、希望、回忆、失去 | 空镜+光影+慢动作 |
| 时间 | 黄昏、黎明、深夜、四季 | 不同时段的光线变化 |
| 空间 | 房间、车内、海边、山顶 | 场景空间展示 |

### 情绪曲线设计
将歌词情绪绘制成曲线，匹配画面：
- 低沉段 → 暗色调、慢镜头、空镜
- 上升段 → 光线渐亮、镜头推进
- 高潮段 → 高饱和、快切、大场景
- 回落段 → 渐暗、慢动作、留白

---

## 第四步：风格匹配

详见 [style-recognition.md](style-recognition.md)。

匹配流程：
1. 从音频分析获取曲风标签
2. 从歌词分析获取核心意象
3. 查表匹配视频风格
4. 如果曲风不明确，根据情绪选择：悲伤→真人电影感，欢快→明亮治愈，激烈→动作感
5. 用户指定风格优先

---

## 第五步：分镜设计与视频生成

### 分镜表模板（1分钟 = 5个镜头）

| 镜头 | 时长 | 对应歌词 | 画面描述 | 镜头运动 | 色调 |
|---|---|---|---|---|---|
| 1 | 12秒 | 主歌第1-2句 | 雨夜街道，人物撑伞独行 | 慢推 | 冷蓝 |
| 2 | 10秒 | 主歌第3-4句 | 咖啡店橱窗，倒影 | 固定 | 暖黄 |
| 3 | 12秒 | 预副歌 | 人物抬头，光线渐亮 | 仰拍上摇 | 渐亮 |
| 4 | 15秒 | 副歌 | 城市天台，逆光奔跑 | 跟拍+环绕 | 高饱和 |
| 5 | 11秒 | 副歌尾句 | 黎明海边，人物背影 | 航拍拉远 | 金橙 |

### seedance 视频生成

#### 方式一：text_to_video（直接文生视频）
```
prompt: "电影质感，真人风格，雨夜街道，一个年轻人撑伞独行，
路灯暖光，雨水滴落，浅景深，35mm胶片颗粒，慢推镜头，
冷蓝色调，氛围感，1080p"
duration: "10-15"
ratio: "16:9"
```

#### 方式二：image_to_video（先生成关键帧再转动效，更可控）
1. 用 seedream 生成关键帧图片
2. 用 image_to_video 将图片转为动态视频
3. prompt 描述镜头运动："缓慢向右平移，轻微推拉，保持画面内容不变"

#### 生成注意事项
- 每个镜头独立生成，保持风格一致（在 prompt 中重复风格关键词）
- 人物镜头尽量避免正脸特写（AI生成人脸易崩），用背影、侧脸、远景
- 转场处的画面要有衔接感（前一个镜头的结束色调≈下一个镜头的开始色调）
- 生成失败时重试，或调整 prompt 简化画面

---

## 第六步：合成与输出

### byted-mediakit-editing 合成顺序
1. 导入 4-6 个视频片段，按分镜顺序排列
2. 转场：淡入淡出 0.5-1 秒（氛围感视频用软转场，不用硬切）
3. 导入原曲音频，对齐视频
4. 添加歌词字幕：
   - 逐句同步，底部居中
   - 字体：电影感衬线体或简洁无衬线体
   - 颜色：白色带黑色描边，确保在任何画面上可读
   - 当前句高亮，已唱句变暗
5. 可选：开头 3 秒显示歌曲名+作者（淡入淡出）
6. 结尾 2 秒渐黑
7. 导出：MP4，H.264，1080p，16:9，音频 320kbps AAC

### 音量
- 原曲：0dB（主音轨）
- 不添加额外 BGM（原曲就是 BGM）
- 视频片段原生音轨：静音

### 质量检查
- [ ] 画面风格统一（不混用真人/二次元）
- [ ] 镜头节奏与 BPM 匹配
- [ ] 歌词字幕同步且可读
- [ ] 转场自然，无跳帧
- [ ] 总时长 45-75 秒
- [ ] 原曲音频清晰无杂音
