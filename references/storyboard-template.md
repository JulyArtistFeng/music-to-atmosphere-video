# 分镜设计模板与歌词画面映射

设计分镜时读取。本文档提供歌词→画面映射方法、分镜表模板和各风格分镜示例。

---

## 分镜设计原则

### 1分钟视频的镜头分配
| 镜头数 | 单镜头时长 | 适用场景 |
|---|---|---|
| 4个 | 15秒 | 慢歌、氛围向、长镜头 |
| 5个 | 12秒 | 通用，最常用 |
| 6个 | 10秒 | 快歌、节奏强、多场景 |

### 镜头与歌曲段落对应
```
0:00-0:12  镜头1：主歌开始（建立场景/人物）
0:12-0:24  镜头2：主歌延续（细节/动作）
0:24-0:36  镜头3：预副歌（情绪上升，光线变化）
0:36-0:51  镜头4：副歌（高潮，大场景/强情绪）
0:51-1:00  镜头5：副歌尾句（收束，留白/远景）
```

## 歌词→画面映射方法

### 方法一：直接视觉化（歌词有具体场景）
歌词直接描述了画面，直接还原：
- "站在雨中的路口" → 雨夜街道，人物站在路口
- "海边的日落" → 海边黄昏，太阳落下
- "城市的霓虹" → 城市夜景，霓虹灯

### 方法二：意象视觉化（歌词有抽象意象）
提取核心意象，用视觉符号表达：
- "孤独" → 空旷房间、一个人的背影、拥挤人群中的独处
- "回忆" → 老照片、模糊的窗户、逆光中的旧物
- "希望" → 破晓光线、门缝中的光、奔跑向远方
- "失去" → 空椅子、消散的烟雾、远去的背影

### 方法三：情绪驱动（歌词太抽象）
完全根据情绪设计画面，不对应具体歌词：
- 悲伤 → 雨天、慢动作、冷色调、空镜
- 欢快 → 阳光、奔跑、高饱和、快节奏
- 激昂 → 大场景、逆光、强对比、运动镜头
- 治愈 → 自然光、温暖场景、浅景深、慢推

## 情绪曲线与画面节奏

### 标准情绪曲线（流行歌）
```
情绪
 ↑        ╱╲ 副歌
 │      ╱    ╲
 │    ╱预副歌  ╲
 │  ╱主歌       ╲尾奏
 └────────────────→ 时间
```

画面匹配：
- 主歌（低）：近景、细节、暗色调、慢镜头
- 预副歌（升）：中景、光线渐亮、镜头推进
- 副歌（高）：远景/大场景、高饱和、运动镜头
- 尾奏（降）：远景、慢动作、渐暗/留白

### 快歌节奏
- BPM > 130：镜头切换更频繁（6-8个镜头），可用快切
- 每个镜头 7-10 秒
- 镜头运动更动感（跟拍、快推、旋转）

### 慢歌节奏
- BPM < 90：镜头更少更长（3-4个镜头）
- 每个镜头 15-20 秒
- 镜头运动极慢（慢推、固定、航拍）
- 多用空镜和自然风景

## 人物处理技巧

AI 生成视频时人脸容易崩坏，建议：
1. **优先用背影/侧脸/远景**，避免正脸特写
2. **人物占画面比例小**，重点在场景和氛围
3. **用剪影和逆光**，不需要清晰面部
4. **多人场景**用人群背影，不聚焦单个人
5. 如果必须正脸，用 image_to_video 从一张高质量人脸图开始，降低崩坏概率
